# HTMLプレビュー（ブラウザ自動起動）

`$ bunx @marp-team/marp-cli slide/slides.md --preview`

# HTML出力

`$ bunx @marp-team/marp-cli slide/slides.md --output docs/index.html`

# PDF出力

`$ bunx @marp-team/marp-cli slide/slides.md --pdf --output slide/slides.pdf`

# PPTX出力

`$ bunx @marp-team/marp-cli slide/slides.md --pptx --output slide/slides.pptx`
